# 🚀 BikeLedger – Smart Motorcycle Showroom Management System

### Full-Stack MERN Application | Cloud Computing | DevOps | CI/CD

**BikeLedger** is a full-stack motorcycle showroom management application designed to simplify and automate daily showroom operations. It provides a centralized platform for managing customers, motorcycle inventory, billing, EMI calculations, payment transactions and financial reports.

The application is developed using the **MERN stack (MongoDB, Express.js, React.js and Node.js)**, providing a scalable architecture, efficient data management and a responsive user interface.

Beyond application development, BikeLedger incorporates a **DevOps and cloud deployment approach** using Docker, Jenkins, AWS EC2 and ngrok to support containerization, continuous integration, deployment automation and secure development access.

## 💡 Project Objectives

- Digitize motorcycle showroom operations through a centralized management platform.
- Simplify customer management, inventory tracking and billing operations.
- Automate EMI calculations using annual simple interest.
- Maintain accurate payment records, outstanding balances and overdue installment tracking.
- Apply modern containerization and DevOps practices for application deployment.

## ⚙️ DevOps & Cloud Integration

- **Docker:** Containerize the frontend and backend for consistent application execution.
- **Docker Compose:** Manage application services using a unified configuration.
- **Jenkins:** Automate build, testing and deployment workflows through CI/CD pipelines.
- **AWS EC2:** Host and deploy the application on cloud infrastructure.
- **ngrok:** Provide secure temporary public access to locally hosted services and support webhook integration during development.
